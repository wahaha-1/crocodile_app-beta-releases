# LexiMed Beta

LexiMed Android Beta 安装包与更新渠道，用于体验开发中的功能。

- 应用名称：**LexiMed Beta**
- 独立包名：`com.leximed.beta`
- [下载最新 Beta](https://github.com/wahaha-1/crocodile_app-beta-releases/releases/latest)
- 应用内更新地址：`https://api.github.com/repos/wahaha-1/crocodile_app-beta-releases/releases/latest`
- 支持 Android 8.0 及以上。

Beta 使用独立签名和应用数据，可与原 App 同时安装。Beta 后续更新只从本仓库获取，持续沿用同一 Beta 签名。

本仓库仅保存安装包、校验文件与公开说明。应用源码和签名私钥保存在各自的私有位置。

## 发布约定

版本采用数字标签（例如 `v1.3.0`），发布名称明确标注 Beta。为了兼容现有应用内更新器，本独立 Beta 仓库使用可由 `/releases/latest` 读取的 Release；Beta 身份由独立应用、签名和仓库共同区分。

当前 Beta 的空间整理改造已完成本机验证，实物交互、迁移和真实模型验收仍待补充。三用途正式内容提交继续遵循原有准入，原课程提取入口保留。具体内容与适用范围请阅读各次 Release 说明。
